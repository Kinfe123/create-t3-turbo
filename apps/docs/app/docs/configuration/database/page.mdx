# Database

Database documentation explains how the project connects to persistence, which schema or migration files matter, and what has to be ready before runtime features read or write state.

## Runtime contract
Treat each setting as part of the runtime contract: credentials unlock external services, adapter settings control integration behavior, and project config files decide how the app starts.

## Required environment variables
- `POSTGRES_URL` - The database URL is used to connect to your Supabase database.

## Project config files
- `packages/db/drizzle.config.ts` (database) - Database schema or adapter configuration.

## Verify changes
- Run `pnpm dev` after setting the variables.
- Open the workflow, route, or command that depends on this configuration and confirm it reaches the expected state.
- If setup fails, check missing variables, database connectivity, and adapter-specific settings before debugging application logic.
