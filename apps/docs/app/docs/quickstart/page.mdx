# Quickstart

Use this quickstart to move from a fresh checkout to the first workflow that proves create-t3-turbo is configured and usable.

## Prerequisites
This project uses `pnpm` as its package manager.
Environment-backed behavior is present, so configuration is part of the first-run path.

## Run locally
1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env` and set the required values.
3. Run `pnpm dev` to exercise the main workflow.

## Repository scripts
These commands are useful after the first run because they are the repeatable workflows available in the project.

- `build`: `turbo run build` creates the production build or compiled package artifacts.
- `dev`: `turbo watch dev --continue` starts the local development workflow.
- `typecheck`: `turbo run typecheck` runs static checks before build or release work continues.
